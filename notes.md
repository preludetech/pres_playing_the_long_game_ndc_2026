Build vs Buy 
- disposable software makes Build appealing but
    - lots of dodgy code 
    - reliability, security, thoughful design etc not free 
- Building makes sense when the capability underpins competitive advantage, involves sensitive regulatory data, or requires deep integration into proprietary systems. Buying makes sense for commoditized use cases, when speed-to-value determines success, or when vendors bring compliance coverage you lack internally
